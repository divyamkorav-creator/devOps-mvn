About this project

This project was created using IntelliJ IDEA and JDK 17. The pom.xml file defines project information, dependencies, and build plugins. Maven is used to clean, build, test, and package the Java application.

Tools and technologies

Java 17

Programming language and JDK used for the application.

Apache Maven

Build automation and project dependency management.

Selenium

Browser automation dependency included in the Maven project.

TestNG

Testing framework dependency configured for test scope.

Git

Tracks project changes through commits and branches.

GitHub

Hosts the source code in a public repository.

Build commands

Run these commands from the project directory:

mvn clean mvn compile mvn test mvn clean install

Project workflow

Create a Maven project in IntelliJ IDEA using JDK 17.
Configure project details, dependencies, and plugins in pom.xml.
Build the project using mvn clean install.
Initialize Git, add files, and commit the project.
Connect the local repository to GitHub and push the code.
